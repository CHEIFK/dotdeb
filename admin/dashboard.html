Service Controls — Continental Survival

TARGET: MINDUSTRY-SURVIVAL

Actions in this section strictly target Continental Survival. The other two servers are completely isolated and will not be interrupted.

Start Service

Boot the Mindustry daemon for the selected server.

Restart Service

Gracefully save world and restart the selected server process.

Stop Service

Save game progress and halt the selected server daemon.

Host Machine Power (AWS EC2 Instance)

INSTANCE-LEVEL LIFECYCLE

Controls the physical EC2 virtual machine hosting all three servers. If EC2 is stopped, click Start EC2 to power it on.

Power On EC2 Host

Calls ec2:StartInstances to boot the virtual machine when stopped.

Power Off EC2 Host

Saves all 3 active worlds cleanly, then calls ec2:StopInstances.
